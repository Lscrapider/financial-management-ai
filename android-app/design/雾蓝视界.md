# Android「雾蓝视界」实施记录

本次依据用户选择的 A 方向实施：工作台页首使用雾蓝光学素材，行情、报告和 AI 正文保持纯色阅读面。本文记录本次变化，不覆盖 PRODUCT.md / DESIGN.md 中的业务契约。

## 视觉与工程边界

- FinanceTheme 的全局颜色、字体、Shape、Spacing 不变。FinanceSurfaces.kt 将现有 surface 与 primaryContainer 按 0.35 插值，作为统一的顶部栏、底部操作区和导航表面；浅色约为冷白，深色为低饱和蓝黑。
- 工作台：无卡片页首，生成的光学素材位于右侧；标题和问候独立绘制。概况与报告以细色带分节，数量是视觉重心，保留完整名称、类型、代码与状态。四个工具沿用官方 Phosphor 图标。
- 行情：统一顶部材质，指标细网格按真实字段和大字号适配。图表仍为纯色画布，不新增快捷周期、不调整默认分时/后复权、不恢复刷新按钮。
- AI：淡蓝用户气泡，清晰正文，不透明输入框，48dp 圆形发送控件配官方纸飞机图标；原生按压反馈。保留流式、历史、复制、中断、最多 5 行及 1000 字限制。
- 报告、检索、导入：共享顶部栏及操作栏，选中对象使用明确的主题前景/背景配对。报告阅读、检索片段和 OCR 正文没有纹理。
- 个人中心：平面分节代替连续卡片；登录沿用相同的生成品牌标记。
- 不新增实时模糊、循环动画、着色器或依赖。页首玻璃感来自静态素材；深色下将素材透明度降低到 0.32，保持正文对比。因此 API 26–30 无需模糊降级，所有支持版本走相同绘制路径。
- 工具页隐藏底栏、键盘 Insets、返回、可见时约 10 秒行情更新、图表横屏全屏逻辑未调整。
- 现有加载、缺失、失败、未知、受限与确认流程保留。示例图中的示例行情、额外快捷区间和附加文案不写入应用。

## 生成素材与许可

本次使用内置 imagegen 生成原创品牌素材；没有复制网络摄影或未经许可的插画。

| 生产资源 | 用途 | 格式 |
| --- | --- | --- |
| app/src/main/res/drawable-nodpi/bg_workbench_optics.webp | 工作台右侧页首光学素材 | 768×512，真实 alpha，WebP |
| app/src/main/res/drawable-nodpi/ic_launcher_optics.webp | 自适应桌面图标前景、登录品牌标记 | 432×432，真实 alpha，无损 WebP |
| app/src/main/res/drawable/ic_launcher_optics_background.xml | 桌面图标深蓝底 | 原生纯色 #173D70 |
| app/src/main/res/drawable/ic_launcher_optics_monochrome.xml | Android 单色主题图标 | 对同一前景的 alpha 使用白色 tint，无第二套几何 |

图标前景的主要可见轮廓（alpha ≥ 128）位于画布中心半径 0.296 以内，中心透空；生成的淡边仍需在真实启动器裁切形状下验收。生产素材总计约 83KB；页首解码约 1.5MiB，桌面前景解码约 0.71MiB。旧图标文件保留但入口已切换。

派生暗色图和生成的单色图没有真实 alpha（背景被画成棋盘格），已剔除，不进入生产资源。单色图改为原生 tint 共用经过核验的彩色前景透明通道。

功能图标来自项目现有固定版本 Phosphor / MIT。新增发送图标的原始 SVG 保存在 assets/paper-plane-tilt-fill.svg；VectorDrawable pathData 与该 SVG 原始 path 完全一致，许可记录见 ../THIRD_PARTY_NOTICES.md。

## 实机截图反馈后的修正

- 工作台状态栏与页首使用相同起始色；标题和工具共用连续背景，按图像实际高度淡出，去掉图片底部的硬裁切感。素材仍为先前生成的真实透明图片，不新增实时模糊。
- 标题使用 headlineLarge / Bold，概况数量使用 displayMedium / Bold；缩减区块间留白，保留所有字段和大字号重排。工具按 A 稿排列为 AI 助手、研究报告、知识检索、资料导入，权限和回调不变。
- 标的名使用 displaySmall，最新价使用 displayMedium / Bold；按实际价格和涨跌幅的测量宽度决定上下或左右排列。继续复用原价格/涨跌幅格式。
- 直接读取 K 线接口的 ma5 / ma10 / ma20，Android 不计算均线。日 K、周 K、月 K 和横屏共用绘制；选中位置读数独立成行。缺失值显示短横线、线段断开；价格轴范围包含可见均线。分时保持原价格与均价线。
- 本轮 Kotlin 与资源编译通过；新版本尚未安装到设备作截图比对。用户目前只提供工作台上半屏，详情页最终视觉需追加实际截图核对。
